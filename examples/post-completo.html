Instalação

Este exemplo combina Markdown e HTML confiável para publicação no WordPress.

Script de instalação

set -euo pipefail
curl -fsSL "https://example.com/install.sh" -o install.sh
chmod +x install.sh
./install.sh

Configuração

service:
  port: "{{ app_port }}"
  enabled: true

const message = "<conteudo seguro>";
console.log(message);
